# Fund AegisDNS

AegisDNS is free, MIT-licensed DNS software maintained by Harshil Anuwadia. Sponsorship pays for the work of maintaining it. Everyone gets the same software, whether they contribute money or not.

**[Sponsor on GitHub](https://github.com/sponsors/Harshil-Anuwadia)** · **[Discuss a partnership](https://github.com/Harshil-Anuwadia/aegisdns/issues/new?template=business.md)**

## Individual support

Choose a one-time or recurring amount on GitHub Sponsors. Financial support is optional. Bug reports, documentation and testing are equally welcome. There are no premium features, device limits, license checks or supporter-only security fixes.

## Organization sponsorship

Businesses that depend on AegisDNS can help fund maintenance and public development. These are suggested commitments to discuss, not checkout tiers or service contracts:

| Commitment | Suggested contribution | Proposed recognition |
| --- | --- | --- |
| Maintenance sponsor | US$250/month | Optional linked company name in the public sponsor directory; public development updates |
| Project sponsor | US$1,000/month | Optional company name and description in the directory; acknowledgment in public funding updates |
| Funded engineering | Agreed project quote | Publicly released improvement with agreed acceptance criteria and optional sponsor acknowledgment |

Contributions of other amounts are welcome. Recognition and any reporting arrangements must be agreed with the maintainer. GitHub handles voluntary sponsorship payments and its own payment terms. Sponsorship does not include an uptime guarantee, priority incident response or engineering deliverables. Do not pay a project quote until scope, availability and payment arrangements have been agreed in writing.

## Commission an improvement

Examples include distribution packaging, a deployment integration, performance investigation with reproducible benchmarks, migration tooling, or documentation for a supported deployment. Accepted changes to AegisDNS are released under its open-source license. Funding does not guarantee acceptance of a change that compromises security or project direction.

Begin with the outcome you need, acceptance criteria and preferred timing. The maintainer reviews feasibility and provides a scope and quote before work begins. No project capacity is reserved by an inquiry.

## Deployment assistance

Organizations can request a scoped setup review, migration plan or team handover. You pay for a person's time and expertise. The installation tools, documentation and software remain free. Production access and sensitive configuration should only be discussed through a separately agreed private channel.

## Independence and privacy

- Sponsors receive no query logs, device inventory, installation telemetry or user contact details.
- Sponsorship never changes DNS answers, risk scores, blocklists or allow rules.
- No advertising scripts, remote sponsor images or tracking pixels are loaded by the dashboard funding page.
- Recognition is voluntary, clearly labeled and confined to project materials. Sponsor names are added only after confirmation and consent; links do not imply product endorsement.
- No exclusivity, private security releases, paid feature gates or donor-based support guarantees.

## Start a conversation

Use the dashboard's **Support AegisDNS** page to prepare an inquiry locally, or [open a partnership issue](https://github.com/Harshil-Anuwadia/aegisdns/issues/new?template=business.md). GitHub issues are public; share only an organization name and a non-sensitive description. Do not post credentials, query logs, billing details or vulnerability reports.
